# Personal Dotfiles & Rice Base

Este repositorio contiene la base de desarrollo para un sistema operativo personalizado sobre **CachyOS** y **Hyprland**, construido de forma modular, ligera y mantenible.

## 1. Filosofía del Proyecto
- **Base principal**: Basado en la arquitectura Lua de HakuSpace.
- **Enfoque**: Modularidad, rendimiento, estabilidad y estética propia sin duplicación de recursos.
- **Compositor único**: Hyprland.

## 2. Fuentes de Inspiración y Referencias
- **HakuSpace**: Arquitectura base, sistema de symlinks, temas y configuración en Lua.
- **iNiR**: Referencia para el diseño de la interfaz gráfica de configuración (GUI).
- **Serpantinum**: Ideas para Lockscreen, selector de wallpapers y Centro de Control (SwayNC).
- **Noro18**: Módulos y estilos para Waybar y Rofi.

## 3. Estado del Proyecto
Actualmente en fase de **Preparación y Reestructuración de Identidad**. 
Las rutas y configuraciones internas de usuario se gestionan progresivamente.
